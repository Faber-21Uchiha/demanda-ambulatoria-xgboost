# Documentos

En esta carpeta se alojan las versiones del documento de grado y la bitácora de decisiones del proyecto.

- `DocumentoGrado_Avance1_Aleman_Mendoza.pdf`: primer avance (OE1).
- `DocumentoGrado_Avance2_Aleman_Mendoza.pdf`: segundo avance (OE2 y OE3 agregado).
- `DocumentoGrado_Entrega_Final_Aleman_Mendoza.pdf`: entrega final (OE1 a OE5, documento para biblioteca).
- `DocumentoGrado_Entrega_Final_Aleman_Mendoza.docx`: versión editable de la entrega final.

Los archivos PDF se incorporan a esta carpeta al cierre de cada entrega. El repositorio no versiona los archivos editables intermedios.
